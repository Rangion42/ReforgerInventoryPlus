## Workshop Description

```md
Reforger Inventory+ is a lightweight inventory quality-of-life mod for Arma Reforger.

Current features:
- Inventory search
- Aggregate ammo/medical counts
- Category quick transfer for weapons, ammo, medical, equipment, and all items
- Color-coded capacity/weight indicators
- Enhanced vicinity item view

Current target:
- Arma Reforger stable 1.6.0.119
- Experimental 1.7 compatibility is being monitored but not yet claimed

Compatibility testing wanted:
I am especially looking for reports from servers using RHS: Status Quo, ACE Anvil, Bacon Loadout Editor, WCS-style packs, HQC/Conflict variants, and wearable storage mods.

Please report bugs with:
- Game version
- Full mod list and load order
- Single-player / hosted / dedicated server
- Repro steps
- Screenshots or logs if available

Source and issues:
https://github.com/Rangion42/ReforgerInventoryPlus

Created and maintained by Rangion42. Please preserve credit if you fork, reuse, or bundle this work.
```
